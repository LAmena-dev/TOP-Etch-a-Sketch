# Etch-a-Sketch
A JavaScript project emulating an Etch-a-Sketch using functions, loops, and the Math module.

## Technology used
* HTML
* CSS (Flexbox)
* JavaScript (Functions, loops, DOM Manipulation, Math Module)

## Features
* Grid up/downsizing
* Coloring and saturation of random colors on mouse over
* Grid color reset
